# 025 — Revisión de UX

La [revisión del 2026-11-24](revision.md) de toda la interfaz contra la
[guía de UX](../../constitution/ux-guidelines.md) se convierte en seis
specs, una por fase (decisión de la propietaria, 2026-11-24):

| Spec | Qué | Hallazgos | Estado |
|---|---|---|---|
| [025a](../025a-errores-visibles/spec.md) | Errores visibles | B1–B4 | **hecha** (2026-11-24) |
| [025b](../025b-ventana-principal/spec.md) | Ventana principal: resultados a la vista, barra lateral, barra de herramientas | F1, F2 | borrador, opciones exploradas |
| [025c](../025c-menus-y-convenciones/spec.md) | Menús y convenciones de Windows | F3, F4 | borrador |
| [025d](../025d-estados-vacios-y-confirmaciones/spec.md) | Estados vacíos y confirmaciones | F5, F8 | borrador |
| [025e](../025e-notacion-y-unidades/spec.md) | Notación, decimales y unidades | F6, F7 | borrador |
| [025f](../025f-ayuda-accesibilidad-progreso/spec.md) | Ayuda contextual, accesibilidad y progreso | F9–F12 | borrador |

Orden propuesto: a → b → c → d → e → f. La 025b cambia el sitio de
muchos controles, así que las siguientes se planifican sobre ella.
