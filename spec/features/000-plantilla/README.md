# Plantilla de feature (SDD)

Copiar esta carpeta a `../features/NNN-nombre/` para cada feature.

## spec.md

- Qué se construye y por qué (user story + contexto).
- Criterios de aceptación verificables.
- Fuera de alcance.
- Referencias (análisis en `../../../Referencias/Ejemplos/`, bibliografía).

## plan.md

- Decisiones técnicas y alternativas descartadas (con motivo).
- Archivos/capas afectados.
- Riesgos.

## tasks.md

- Lista ordenada de tareas con casillas; cada tarea pequeña y verificable.
